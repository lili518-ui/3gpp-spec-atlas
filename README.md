# 3GPP Spec Atlas

**Architecture-to-Clause Navigator for 3GPP Rel-15 to Rel-19.** From architecture to the exact page.

**Open it in your browser:** https://lili518-ui.github.io/3gpp-spec-atlas/

## What it does

- Six linked architecture maps (5G Core, RAN, non-3GPP access, EPS, IMS, CS/GPRS) with 113 network functions and 240 reference points.
- Click a reference point to see the clause that defines it, then open the official ETSI PDF of the chosen release at that exact page.
- Switch releases from Rel-15 to Rel-19 and see the architecture change; compare releases down to individual clauses.
- A reference-point matrix for each map and a 4G → 5G counterpart view.
- Search clause titles across the 21–38 series (1,381 TS catalogued) and the full text of the 309 specs on the maps.

## Use it offline

Download `index.html` (about 9 MB) and open it in a current Chrome or Edge. Navigation and search work offline; the specification PDFs open from ETSI's website, so they need an internet connection.

## Data and attribution

The page stores clause numbers, clause titles, page numbers and links derived from the ETSI publications of the 3GPP specifications. It does not contain the specification text. The specifications are © 3GPP Organizational Partners (ARIB, ATIS, CCSA, ETSI, TSDSI, TTA, TTC) and are served by ETSI.
