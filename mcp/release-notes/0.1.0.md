First release of the Atlas MCP: release-exact 3GPP clause locations from the 3GPP Spec Atlas (data v0.10.0, snapshot 2026-10-28), as a Python library, a local stdio MCP server and an in-process enrich API for log tools.

**Assets**
- `atlas-slim.db` (about 9 MB) + `atlas-slim.json`: the nine lexicon specs (24.301, 24.501, 29.244, 29.272, 29.274, 36.331, 36.413, 38.331, 38.413) plus catalogue tables. Enrich results are identical to the full database. Meant for embedding (Mobile Maven).
- `atlas-full.db` (about 82 MB) + `atlas-full.json`: all 1,381 specs, Rel-15 to Rel-19, with the full-text index. Meant for the MCP server.
- Each manifest carries the Atlas version, snapshot date, size and SHA-256. Pin a tool to this tag and check the hash.

**Interfaces**
- MCP server: `atlas-mcp` (stdio), 11 read-only tools, default Rel-17
- Enrich API: `atlas_core.enrich.Enricher`, contract `atlas-enrich/1`, with QXDM log-code hints

**Quality**: 38 tests (including a 200-anchor citation golden test against the page's JavaScript); where-defined 50/50, lexicon 150/150, out-of-scope 30/30, identifier guard 4/4; Mobile Maven's 84 QXDM names give 58 ok, 26 not_found. The eval answers, the curated causes and timers, the QXDM hints and the reading routes are still marked `reviewed: false`.

See `mcp/README.md`.
